# Security

This policy applies to every Git Hospital repository that does not have its own `SECURITY.md`.

## Reporting a vulnerability

Please do not open a public issue. Use the "Report a vulnerability" button on the repository's Security tab (GitHub private vulnerability reporting). Only the maintainers can see the report.

The projects are maintained by a small team. You will get an acknowledgement and an honest estimate of when a fix can ship. When a fix is released, the advisory credits you unless you ask otherwise.

## Supported versions

Fixes go into the latest release. Older releases are not patched.
